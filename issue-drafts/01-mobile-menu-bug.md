# [BUG] Mobile menu not visible on small screens

## Describe the bug
The mobile navigation menu is hard to access on phones. The menu button needs to be more visible and the menu should open cleanly on all small screens.

## To reproduce
1. Open the site on a phone or in a narrow browser window.
2. Try opening the navigation menu.

## Expected behavior
A visible mobile menu icon should appear and open the navigation links reliably.

## Additional context
This is important for mobile visitors who need easy access to navigation and booking links.
