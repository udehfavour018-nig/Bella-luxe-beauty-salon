# Bella Luxe Beauty Salon

A static beauty salon website showcasing services, gallery, pricing, and contact details.

## Website
- Local preview: open `index.html` in your browser
- GitHub Pages: enable Pages in the repository settings and choose the `master` branch

## Structure
- `index.html` — home page
- `about.html` — about page
- `services.html` — services page
- `pricing.html` — pricing details
- `contact.html` — contact page
- `gallery.html` — gallery page
- `css/style.css` — site styles
- `js/script.js` — site interactions
- `images/` — image assets

## Usage
```bash
git clone https://github.com/udehfavour018-nig/Bella-luxe-beauty-salon.git
cd "Bella luxe beauty salon"
# open index.html or host with GitHub Pages
```

## Notes
- The site is static HTML/CSS/JS
- There is no backend server required
- Images are stored in `images/`
